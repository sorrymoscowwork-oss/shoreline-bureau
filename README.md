# SHORELINE BUREAU

Independent Property & Place Advisory — Hurghada, Egypt.

## Project principles
- Static-first website; no paid hosting, database, or third-party runtime services.
- English and Russian in the first release.
- White canvas, graphite typography, architectural photography, fine rules, restrained terracotta accents.
- Advisory positioning: no property catalogue and no undisclosed seller commissions.

## Local preview
Open `public/index.html` in a browser. The site uses plain HTML, CSS, and JavaScript; no build step or package dependencies are required.

## Deployment
Cloudflare Workers Static Assets on the Free plan. Deploy with `npm run deploy` after authenticating with Cloudflare CLI.
